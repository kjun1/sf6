## 必殺技

<a id="sunshoot"></a>

### 236P：サンシュート

弾が一度進んで停滞し、再び動く。ボタンホールドにより再移動の挙動が変わる。

**目的：空間制圧、相手の前進・ガード・パリィ・ジャンプを誘導し、弾を盾にラインを上げること。**

- 弱・中・強で弾道やタイミングが異なる。強版は上方向へ飛ぶ。
- 初回接触時と再射出時では有利不利が異なる。単一の固定ガードFを全状況に当てはめない。
- 弾抜け・高速DRが届く距離では撃つこと自体がリスク。
- `OD.236P`は2D消費。有利を作る選択肢だが、自分のD残量を見る。
- 端の投げ後は[弾の持続重ね](okizeme.md#throw-projectile)を参照。

<a id="od-sunshoot-input"></a>

#### ODサンシュート：同時押しの組み合わせ

| 版 | 入力表記 | 同時押し |
| --- | --- | --- |
| OD弱 | `OD.236P[弱・LP+MP]` | LP+MP |
| OD中 | `OD.236P[中・LP+HP]` | LP+HP |
| OD強 | `OD.236P[強・MP+HP]` | MP+HP |

いずれも2D消費。弾の版を固定したいセットプレイでは、使う2ボタンまで指定する。
[端の中ライズ後のDR弾重ね](okizeme.md#rise-dr-projectile)は通常弱・OD弱を区別する。

<a id="sunflare"></a>

### 214P：サンフレア／214LPによるS回収

#### 回収

- `214LP`：サンシンボル1個補充。全体48F、ホールドで継続回収可。
- サンシンボルは開始時1S、最大4S。
- 1S確保が強化 `214HP` を使ったガード攻めの閾値。

#### ガード硬直差

| 技 | S使用 | ガード時（接触タイミングで変動） | 判断 |
| --- | ---: | ---: | --- |
| `214MP` | 0S | -4〜-1F | ノーゲージ接触・締め。密着なら反撃や暴れに注意 |
| `214HP` | 0S | -4〜-1F | 強化されていないので不利 |
| `214HP` | 1S | +4〜+8F | ガード有利を取る主力 |
| `214HP` | 2S | +5〜+9F | 削り・有利を強化 |
| `OD.214P` | 0S | +4〜+8F | 0Sでも有利、2D消費 |
| `OD.214P` | 1S | +5〜+9F | 有利強化、2D消費 |
| `OD.214P` | 2S | +9〜+13F | 大きな有利、2D消費 |

1S以上なら、**ガードさせても有利を作れる**。届く打撃・投げ、途中の割り込みは別条件。
ガード後は[攻め継続](pressure.md#enhanced-pressure)、
端でヒットしたら[S回収ループ](okizeme.md#corner-loop)を参照。

### 236K：サンライズ

| 技 | 発生 | ガード時 | 特徴 |
| --- | ---: | ---: | --- |
| `236LK` | 8F | -24F | 1〜14F対空無敵、対空の主力 |
| `236MK` | 13F | -23F | コンボ締め。対空無敵なし |
| `236HK` | 27F | -25F | 打ち上げ・空中追撃用。対空無敵なし |
| `OD.236K` | 14F | -3F | 2D消費、無敵なし |

通常版はガード時の損失が大きい。弱は対空、中・強はコンボ用途を基本とする。
**強サンライズには対空無敵がない。**

/ [中ライズ締め後](okizeme.md#after-ender)を参照。

## その他の入力

<a id="air-followups"></a>

### 4HP~HP / j.HK~HK：対空からの追撃に使うTC

- `4HP~HP`：ルミナスアッパー。1段目は14Fで、対空ヒット後に追撃する公開例がある。
- `j.HK~HK`：サテライトリープ。空対空から2段目を遅らせ、着地後に拾う型がある。

完全入力・高さ条件は[空中の接触別コンボ](combos/air.md#anti-air)へ。
弱ライズの対空無敵と、これらのTCが間に合うことは別の判断になる。

<a id="glow-touch"></a>

### 4MK / 4MK~HP：グロータッチ

**4MKは発生9F。後ろ入力から出せる反撃・PC追撃の候補。** 5MKは発生8Fなので、後ろ歩きからMKを押すときは使う技を区別する。

- `4MK~HP`：HP派生のTC。5LP[PC]・2MP[PC]からつなぐ[小さい隙への反撃](combos.md#route-punish-fast)にも使う。
- `4MK[PC] > 5MK`：HP派生を使わず、PC後に5MKへ目押しする[別ルート](combos.md#route-shimmy-4mk)。

始動の4MKと、後続5MKやHP派生が届く距離はそれぞれ確認する。

### サンバニッシュ

- `4KKK`：後方サンバニッシュ（逃げ移動）
- `6KKK`：前方サンバニッシュ（前方攻撃）
- `2KKK`：上方サンバニッシュ（中段攻撃、ガード+2F）

<a id="sun-order"></a>

#### 214214P：サンオーダー（SA2）の条件

**SAゲージ2本を使い、設置した弾のヒット中に攻撃・回収・移動を組み込む。**
[ヒット時のコンボ](combos/sa2.md)、[ガード後の攻め](pressure.md#sa2-pressure)、
[表裏の続き](okizeme.md#sa2-crossup)へつなぐ。

| ボタン強度 | 弾の発生・掲載値 | このノートの収録用途 |
| --- | ---: | --- |
| `214214LP` | 103F | 具体的なルートは今後追加 |
| `214214MP` | 68F | TC・回収・入れ替え・DI・前j.MK締め |
| `214214HP` | 98F | ODライズからの発動、運び・火力 |

弱中強で弾の射出位置も異なる。レシピの中入力・強入力をそのまま交換しない。

| 消費S | 単体の基礎ダメージ |
| --- | ---: |
| 0S | 1,600 |
| 1S | 2,400 |
| 2S | 3,400 |

- 消費1Sなら開始1S以上、消費2Sなら開始2S以上が必要。
- Sを2個以上持っていても、`[消費1S]`のレシピは1S消費でホールドを止める。
- **全体13Fは発動動作の長さ**。弾の発生103 / 68 / 98Fとは別の値。
- コンボ補正欄は即時補正20%、最低保証40%。単体値をコンボ合計へそのまま足さない。

1S消費のホールド閾値は掲載値26F、2S消費は73F / 76Fと資料間で差があるため、
レシピは消費するS数を指定する。

## 戦略への対応

- **ヒット／ダウン**：236K締めなどで状況を作り、[S回収／弾設置／再接触](okizeme.md#after-ender)へ。
- **ガード**：強化フレア・ODフレアの有利から[攻め継続](pressure.md#enhanced-pressure)へ。
- **空振り・置き技を見せられる**：通常技を押さず歩いて空振りを誘う。投げの空振りを誘えたら [シミー確反](punish.md#shimmy) を選ぶ。
- **相手DR**：反応の本命は2MP、発生が必要なら5LK。詳しい状況は [生DRの止め方](neutral.md#anti-rush)。
