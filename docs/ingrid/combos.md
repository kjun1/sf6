# イングリッド：コンボと記法

> **コンボは基本戦略を実行するための手段**。先に [戦略](strategy.md)・[地上戦](neutral.md)・[画面端の攻め](corner.md) を考え、その状況に必要なコンボだけを優先する。

## 現時点の保存方針

- **技列を省略せず、1本ずつ完全表記で残す**。まず始動／位置／ヒット条件／SとD／ダウン後の行動を整理する。
- Starter / Linker / Ender / Frag への分割は、十分なルートが集まってから行う。
- パーツを参照する省略表記は後で作る。完全表記が正本。
- コンボ以外の起き攻め行動・ストック回収は技列の末尾に混ぜず、別の行に書く。
- 個別の検証履歴・検証ステータスは管理しない。
- 以前の大量列挙は [移行用の旧コンボメモ](../../archive/ingrid-combos-20261011.md) に保存。攻略用の正本とは区別する。

## コマンド・記法

| 表記 | 意味 |
|---|---|
| `5LP/5LK/5MP/5MK/5HP/5HK` | 立ち通常技（`5` は省略可能） |
| `2MP` 等 | 方向（テンキー）＋ボタン |
| `>` | 目押し・リンク・ヒット後の追撃 |
| `:` | キャンセル |
| `~` | ターゲットコンボ／派生 |
| `j.` | 空中入力 |
| `OD.` | OD版 |
| `DR` | 生ドライブラッシュ |
| `DRC` | キャンセルドライブラッシュ |
| `dl.` | 遅らせ |
| `[CH]` / `[PC]` | カウンター／パニッシュカウンター |
| `[Corner]` / `[Air Hit]` | 画面位置・ヒット状況 |
| `S` / `D` | サンシンボル／ドライブゲージ |

SA：`236236K`＝SA1、`214214P`＝SA2、`236236P`＝SA3。

**Sの「開始時必要数」と「消費数」は別**。以前のメモで両者が混同されたため、必要なら `start: 1S` `spend: 1S` と書く。

## 優先して管理するコンボ

### 1. DR反応止め：2MPカウンター

```text
[CH] 2MP > 5MK:214MP
[CH, 開始1S以上] 2MP > 5MK:214HP
```

`2MP` は通常ヒット+6F、CH+8F。後続の `5MK` は8Fなので、**CH・最速入力・5MKの届く距離が成立前提**。反応止めを失敗した状況にまで適用しない。

### 2. 中距離の接触から締める

```text
5MK:214MP
2HP:214MP
[開始1S以上] 5MK:214HP
[開始1S以上] 2HP:214HP
```

`214HP` の強化版はガードされた場合にも有利を取るための選択肢。ただし通常技キャンセル後の割り込み・距離は別に扱う。

### 3. DRCからダウン

```text
2MK:DRC > 5HK > 5MP~MK:236MK
2MP:DRC > 2HP:236HK > j.214LP
5MK:DRC > 2HP:236HK > j.214LP
```

`2MK` と `2MP`・`5MK` は無条件に始動技を交換できない。`2MK` 通常ヒットの `DRC > 2HP` は安易に採用しない。

### 4. 強化ビーム後の締め

```text
[2S] 5MP~MK:214HP > 6KKK
[2S, OD版] 5MP~MK:OD.214P > 2KKK > 236MK
```

前者は2S強版を使った前方サンバニッシュのルート、後者は2S OD版の上方サンバニッシュ追撃。**通常版 `214HP > 2KKK` を一般的な中央ルートとして記録しない**。

### 5. 画面端でSを回収して攻めを継続

```text
[Corner, 開始1S]
combo: 5MP~MK:214HP > 236HP
after: 214LP（S回収、起き上がりに対して約+4Fを狙う）
```

これは連続技とセットプレイを区別した表記。詳細は [画面端の攻め](corner.md)。

### 6. 端・BO・DIスタン

最終目標に直結するが、必要なS・SA量や状況で火力が変わるため、ここでは単一の「4割確定ルート」を固定しない。採用する場合は **相手の残体力、開始S、使えるSA、スタン状態**とセットで記録する。

## 接触後に使う実戦ルート

コンボ単体ではなく、ガード後のジャンケン、シミー、確定反撃、締め後の時間消費まで含めた判断は **[行動分岐プレイブック](decision-playbook.md)** に集約する。ダメージは参照資料にあるレシピ単位の参考値で、技の高さ・距離・調整後の差を確認する。

| 成立状況 | 完全表記（コンボ部分） | 参考ダメージ | 消費・結果 |
|---|---|---:|---|
| `DR > 5HK` 通常ヒット | `DR > 5HK > 5MP~MK:236MK` | 2,680（攻略メモ） | 1D、S0、中ライズ起き攻め |
| 同上、S回収へ | `DR > 5HK > 5MP~MK:214MP` | 2,500（攻略メモ） | 1D、S0、後で `214LP` 回収 |
| +2Fから `2LK` ヒット（2発） | `2LK > 2LP:236MK` | 1,290（攻略メモ） | 追加D/S0、中ライズ |
| +2Fから `2LK` ヒット（3発） | `2LK > 5LP > 5LK:236MK` | **1,370** | 追加D/S0、中ライズ |
| シミー後 `5MK[PC]` | `5MK[PC]:236HK > j.214LP`／`j.214MP` | **未実測** | 0D、弱空フレアならS+1。先端接続を確認 |
| シミー後 `5HK[PC]` | `5HK[PC] > 5MP~MK:236MK` | 2,840（攻略メモ） | 0D、距離条件あり |
| 無敵技ガード確反 | `2HP[PC]:236HK > j.214LP` | **2,260** | 0D、S+1、前ステ後+5Fの例 |
| 無敵技ガード確反・火力 | `2HP[PC]:236HK > j.214MP` | **2,890** | 0D、S0、2前ステ後+9〜10Fの例 |
| 無敵技ガード確反・D投入 | `5HP[PC] > DR > 2HP:236HK > j.214LP` | **2,391** | 1D、S+1、前ステ後+5Fの例 |
| 無敵技ガード確反・SA3 | `2HP[PC]:236HK > dl.j.MP > SA3` | **5,080** | SA3、低空ヒットのタイミング条件 |

`DR > 5HK` と `5HK[PC]` の合計ダメージは公開攻略メモ値を記載。`5MK[PC]` については、2026-08-03調整により強サンライズ接続が可能だが、弱／中空フレアへ締めた場合の総ダメージは未実測のため他の始動から推算しない。

## パーツ化の将来方針（現在は保留）

概念は **Route（技列）／Part（再利用する名前付きRoute）／Combo（条件・コスト・結果付き完全Route）**。

候補の役割は以下の4つ。

| 役割 | 意味 |
|---|---|
| `starter` | 始動側の再利用技列 |
| `linker` | 中継 |
| `ender` | 締め |
| `frag` | 役割を限定しない共通部分 |

- 全コンボを機械的に分割しない。
- `5MP~MK` のようなTC単体は基本直書き。
- 参照時の接続記号（`>`、`:`、`~`）は参照元Routeが所有する。
- 重複する短い技列より、**分岐点・変更理由・実戦の選択単位**を優先してPart化する。
- Part参照の循環は禁止。Partの複雑なパラメータ化は当面行わない。
- Partの同一性は展開後の技列と固有の成立条件で判断する。
