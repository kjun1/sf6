<a id="strategy-constraints"></a>

## 戦略を選ぶ材料

相手の行動への回答に加えて、[どの戦略が取りやすいか](../strategy.md#comparison)も考える。

| 見るところ | 比較したいこと |
| --- | --- |
| 回収を咎める手段と射程 | 接触を抑えてSを蓄える時間が作れるか |
| 接触を拒否する手段 | ガード圧力でDや位置を奪う機会があるか |
| 迎撃・反撃の機会 | Sを使った高火力に変換できる始動を狙えるか |
| 体力・時間・画面位置 | 準備を続けるか、方針を切り替えるか |

相手キャラごとの優劣は、具体的な技・距離・局面と合わせて検討する。

<a id="common"></a>

## 共通対策

### 接触前：前進・迎撃・技の使い分け

| 相手の行動 | イングリッドの回答候補 | 詳しく見る |
| --- | --- | --- |
| 生DRで接近する | `2MP`でリターン、`5LK`で速さを取る | [DR止め・CH条件](../neutral.md#anti-rush) |
| ジャンプで地上技・弾を避ける | 弾や置き技を控え、`236LK`や空対空 | [距離別の立ち回り](../neutral.md#by-distance) |
| 後ろ歩きで接触を拒否する | 下段・前進、または距離を保って回収機会を探す | [中距離の接触](../neutral.md#mid-contact) |
| 置き技・差し返しを狙う | 空振りを誘う、技を置かず歩く | [中遠距離の使い分け](../neutral.md#long-range) |
| 弾をパリィする | 連射を減らし、前進か準備を選ぶ。近距離なら投げも候補 | [遠距離の弾と回収](../neutral.md#long-distance) |
| 弾抜けを狙う | 弾を出さず硬直を誘い、反撃する | [遠距離の選択](../neutral.md#long-distance) |
| DIを見せる | キャンセルDI・様子見・投げ等。キャンセル不能技の頻度を調整 | [状況別の優先順位](../neutral.md#priorities) |

### 接触後：相手が攻めを拒否するとき

| 相手の行動 | イングリッドの回答候補 | 詳しく見る |
| --- | --- | --- |
| 最速4Fで暴れる | 有利Fと距離に合う小技・打撃を選ぶ | [+2F後](../pressure.md#dr5hk-guard) / [端の+4F後](../pressure.md#corner-pressure) |
| ガード・パリィで固まる | 投げを混ぜる。強化フレアの後も距離を見る | [ガード後の選択](../pressure.md#dr5hk-guard) |
| 遅らせ投げ抜けを使う | シミーで投げを空振らせて反撃する | [シミー確反](../punish.md#shimmy) |
| 無敵技・SAで切り返す | 様子見を混ぜ、実際にガードできたら反撃する | [ガード後の確反](../punish.md#reversal) |
| 端からジャンプ・バクステ等で逃げる | 打撃・対空・位置維持を選ぶ | [脱出への回答](../pressure.md#escape-counter) |

表は回答を探すための入口。届く距離、ヒット条件、最速入力、相手の技との相性はリンク先で確認する。

<a id="characters"></a>

## キャラ別対策

個別の記事はこれから追加する。**イングリッド → 対戦相手**を明記し、共通対策から変わる部分を書く。

- 相手の技・強度をガードした後、どの反撃が届くか。
- 相手固有の弾・突進・設置・連係への回答。
- 攻める距離、S回収の機会、端の維持で変えること。
- D削り・端攻めとS蓄積・大火力の、取りやすさや切り替え条件。

記事はこのフォルダに相手名で追加し、ここに一覧を作る。[対策ノートの型](../../guide.md#matchup-template)を参照。
