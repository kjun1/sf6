# 戦略仮説：D削り・端攻め

[イングリッド](../README.md) › [戦略の比較](../strategy.md) › D削り・端攻め

**接触・D削り・端への運びを重視する案。** [S蓄積・大火力案](stock-and-burst.md)と並べて検討する。

<a id="win-plan"></a>

## 勝ち筋：Dを削り、端へ運ぶ

**相手のDゲージと画面位置に圧力をかけ、端のBOからDIスタン・リーサルを狙う。** これはこのノートで検討している戦略仮説。

ガードが続けばDが減り、後退すれば端に近づく。その両方を狙う。パリィ・ジャンプ・弾抜けには別の回答を用意する。

| 得たいもの | そのための行動 |
| --- | --- |
| 相手のDを減らす | 通常ガードさせる、相手にDを使わせる |
| 相手を端へ運ぶ | 前進、運び、脱出阻止 |
| 強化フレア用のS | 安全なダウン後などに回収 |
| リーサル圏までの体力削り | 通常ヒット、投げ、削り |
| 自分のD・SAを残す | 不要なDRC・ODを抑える |

スタン後の約4割ダメージは目標の目安で、固定の保証値ではない。BO後も相手のSA・ジャンプ等は残るため、端BOだけでDI確定とはしない。

## 最初の接触と、準備できた後

**最初は通常技と対空でダウンを取り、その後に弾・S・接近を選ぶ。** 毎回密着起き攻めにする必要はない。

| 局面 | 基本行動 | 次に見る |
| --- | --- | --- |
| 初回の地上戦 | `5MK`・`2HP`で触る。DRは`2MP` / `5LK`、飛びは対空 | [距離別の選択](../neutral.md) |
| ダウンを取った | 接近 / 弾設置 / S回収を選ぶ | [締め別の次入力](../okizeme.md#after-ender) |
| Sがあり、接触できる | 強化`214HP`でガード有利を狙う | [フレア後の攻め](../pressure.md#enhanced-pressure) |
| 相手が端・D少 | 大きく下がるより位置とガード圧力を保つ | [端の攻め](../pressure.md#corner-pressure) |

後退にはラインを失うコストがある。弾で行動を制限した後は、前進して位置を取り直す。

## リソース運用

**1Sを確保すると、強化214HPでガード有利を作れる。** 回収のために安全や端圧力を失うなら、即回収はしない。

- Sは開始1・上限4。地上`214LP`で1S回収、全体48F。ホールド可。
- 強`214HP`は保有量に応じ最大2S消費。1Sからガード有利になる。
- `OD.214P`は0Sでも有利を作れるが2D消費。DRCは3D消費。
- 相手のBOを狙う間も自分のD残量を見る。通常技接触から強化フレアを使える場面を重視する。

数値は[フレアの性能](../moves.md#sunflare)、回収の時間は[起き攻め](../okizeme.md#after-ender)を参照。

## 相手の位置 × D残量

| 相手の状況 | 優先すること |
| --- | --- |
| 中央・D多 | 接触→ダウン→S / 弾準備。機会があれば前進 |
| 中央・D少 | ガード圧力で削る。後退を許し続けない |
| 中央・BO | 端へ追い込み、回復前の圧力を維持 |
| 端・D多 | 位置を保ち、打撃・投げ・シミー |
| 端・D少 | D削り。ジャンプ・Dリバーサル・SAも警戒 |
| 端・BO | DIスタンの状況作り。ジャンプ・SAへの回答を残す |

<a id="corner-goals"></a>

## 端で続けたいこと

1. 脱出を防ぎ、打撃・投げ・シミーで防御を崩す。
2. ヒット後は同じ攻めに戻れる締めを選ぶ。
3. Sを使ったら、ダウン後に回収できる状況を探す。
4. BOした相手にはDIの圧力をかける。

BO中はガード硬直が4F増える。連係の隙間は変わるが、残る相手の選択肢も含めて設計する。

- 打撃が通る → [コンボ](../combos.md#route-corner-loop)
  → [S回収](../okizeme.md#corner-loop)
  → [端の読み合い](../pressure.md#corner-pressure)。
- 投げなら[投げ後](../okizeme.md#after-throw)へ。
- 投げ空振りを取れたら[シミー確反](../punish.md#shimmy)へ。
- 無敵技をガードしたら[確反](../punish.md#reversal)へ。

SAゲージ2本を使う候補として、[SA2コンボのDI締め](../combos/sa2.md#sa2-di-ender)と
[SA2ガード発動のD削り](../pressure.md#sa2-pressure)も比べる。
回収・ダメージ・相手Dの減少を別々に見て、端圧力とのつながりを考える。

## 行動を見直すとき

**基本行動 → 相手の回答 → 再回答 → 得た位置・D・S**を一組で考える。歩いてラインを取ることも回答に含める。

相手の防御傾向に応じて打撃・投げ・シミー等の採用率を変える。具体的な相性は[ガード後の攻め](../pressure.md)、相手の回答への再回答は[共通対策](../matchups/README.md#common)を参照。
