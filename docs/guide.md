# ノートのまとめ方

[キャラ一覧](../README.md) · [記法](notation.md) · [イングリッドの実例](ingrid/README.md)

## 1キャラの基本形

**入口で要点をつかみ、必要になった箇所だけ詳しく読む。** キャラガイドの目次は、次の5つにまとめる。

| まとまり | 子のテーマ | イングリッドの例 |
| --- | --- | --- |
| 戦略 | 複数の勝ち筋の仮説 / 同じ局面での比較 | [戦略の比較](ingrid/strategy.md) |
| 使い方 | 立ち回り / 攻め / 守り・反撃 | [使い方](ingrid/README.md#gameplay) |
| 相手への対策 | 共通行動への回答 / 相手キャラ別の回答 | [対策ノート](ingrid/matchups/README.md) |
| 技・コンボ | 技性能 / 始動別の完全ルート / 記法 | [資料](ingrid/README.md#reference) |
| メモ | 分類前の気づき・試したいこと | [自由メモ](ingrid/memo.md) |

### 使い方の中を分ける

- 立ち回り：距離別の行動候補。接触・迎撃・距離維持・回収をどう使うか。
- 攻め：ガード後の読み合いと、ダウン後の起き攻め。端の攻めはその中の状況として扱う。
- 守り・反撃：相手の接近への回答、ガードできた後の反撃選択。

戦略は「なぜ・いつその行動を優先するか」、使い方は「その場面でどう実行するか」を扱う。

「シミーを選ぶ」は攻め、「投げ空振りに何を当てるか」は確反、「完全技列」はコンボ、と役割でつなぐ。
同じ内容を複数のページに複製せず、該当する見出しへリンクする。

### ページを分割するとき

新キャラは概要1ページから始めてよい。内容が増えてから、立ち回り・攻め・起き攻め・確反・コンボ・技データ等へ切り出す。
見出しも「場面 → 条件 → 行動後の処理」の順にし、細部を同じ深さに並べない。

既存ページのパスと参照用アンカーは保ち、キャラ概要と各ページの見出しで階層を表す。
キャラ別対策の記事は使用キャラ配下の対策フォルダにまとめる。
戦略の詳細は戦略フォルダに分け、元の戦略ページは比較の入口として使う。

## 戦略仮説のまとめ方

**キャラ全体の唯一の方針を決める前に、複数の勝ち筋を並べて検討できる形にする。**
各仮説では次の論点をそろえ、相手・位置・リソースなど同じ局面で比較する。

| 論点 | 書くこと |
| --- | --- |
| 狙う勝ち筋 | 何を獲得し、どこでダメージや勝利につなげるか |
| 準備・立ち回り | 接触・回収・前進・待ちのうち何を優先し、何を失うか |
| 当てる入口 | 狙える始動とヒット条件、どのコンボへつなぐか |
| リソース・ダウン後 | S・D・SAの使い方、接近と再準備のどちらを取るか |
| 相手・局面 | 取りやすい条件、崩れる条件、切り替えを検討する場面 |
| 根拠・検討点 | 誰の仮説か、参照した資料、まだ詰めたいこと |

イングリッドでは[D削り・端攻め](ingrid/strategies/pressure-and-corner.md)と
[S蓄積・大火力](ingrid/strategies/stock-and-burst.md)を、[比較ページ](ingrid/strategy.md)から読む。

行動候補・技性能・コンボの完全入力は共通の資料を参照する。
戦略を増やすたびに立ち回りやコンボの本文を複製せず、優先する行動・利益・選ぶ条件の違いを書く。
新しい案を加えたら、キャラガイドの戦略一覧と比較ページにリンクを追加する。

## 読みやすくする基準

- 見出しを「何の場面か」にし、最初の1文に行動・結論を書く。
- 表は原則4列以内。長い成立条件や分岐は表の下へ置く。
- 同じ説明を各ページで繰り返さず、必要な見出しへ直接リンクする。
- 数値や技列は担当ページで管理し、他ページは選ぶ理由を説明する。早見表の数値は参照先を添える。
- 読み合いの表は、こちらが先に選ぶ行動とその相性を示す。相手の選択を見てからすべて返せるという意味にはしない。
- 編集方法・将来の設計はこのページに置き、攻略の本文を短く保つ。

### 分岐・循環を図にする

**結果で進路が変わる手順、同じ状態へ戻る攻め、コンボと準備の区切りはMermaidで描く。** 局面ごとの小さな図に分ける。実例は[DR強Kの分岐](ingrid/pressure.md#dr5hk)、[端のS回収ループ](ingrid/okizeme.md#corner-loop)、[SA2途中の回収](ingrid/combos/sa2.md#sa2-tc-lv1)。

- 技性能・ダメージ・コストの比較や索引は、表を使う。
- 図形の意味は[共通の読み方](notation.md#flowcharts)にそろえる。結果確認と、先に選ぶ読み合いを区別する。
- ヒット種別、位置、開始S、有利F、届く距離などの成立条件を図のそばか矢印に残す。条件付きの参考値を保証値に変えない。
- 循環は戻れる条件を矢印に書く。ガードされた行動からヒット用コンボ・S回収へ無条件につながない。
- 図の略記を完全入力の代わりにしない。詳しい技列・消費・不明点は担当ページの表やレシピに置き、図の外にも参照リンクを付ける。

## コンボは始動から引く

**始動・ヒット条件 → 位置・リソース → 欲しい結果**の順で選ぶ。用途は見出しで示し、同じ始動の回収型・火力型は隣に並べる。

| 完全入力 | ダメージ | 消費・回収 | 条件・目的 |
| --- | ---: | --- | --- |
| `2HP[PC]:236HK > j.214LP` | 2,260（参考） | D0、S+1 | 12Fの反撃猶予があり届く場合。S回収型 |
| `2HP[PC]:236HK > j.214MP` | 2,890（参考） | D0、S増減0 | 同じ始動の火力型 |

これは[既存コンボ](ingrid/combos.md#route-punish)の書式例。ダウン後の行動は[起き攻め](ingrid/okizeme.md#after-ender)へリンクする。

- 完全入力を残す。SAもコマンドで書き、ボタン強度と追加条件を[記法](notation.md#move-variants)に従って区別する。
- SA2の性能指定は`[消費0S]` / `[消費1S]` / `[消費2S]`とし、出典のLv表記から頭の中で換算せず読める形にする。
- 通常ヒット・CH・PC、中央・端、立ち・しゃがみ等の条件を混ぜない。
- Sは開始必要数と消費を分ける。DR・DRC・ODの合計D消費、使うSAも記す。
- 「コンボ」と「その後の回収・空振り・重ね」は別に書く。
- SA2弾がコンボをつなぐ途中の回収・空振り・移動は、非攻撃行動と分かる表記で実行手順に含める。
- レシピが長いテーマは[SA2コンボ](ingrid/combos/sa2.md)のように子ページへ分け、完全入力の置き場所を一つにする。
- ダメージ不明のルートも記録できる。不明値を別始動の差分から推算して埋めない。
- 本数だけで網羅性を判断しない。小技・中距離・CH・確反・端・DI・対空・飛び込み・リーサルのどこが薄いかを示す。
- 詳しい個別の検証履歴・検証ステータスは管理しない。必要な条件と不明点を本文に残す。

## キャラ対策の型

**使用キャラから見た回答**を中心にし、誰が誰と戦う話かを明記する。
共通対策は相手の行動から探す入口、キャラ別対策は相手固有の技・距離・連係への回答とする。

| 内容 | 置き場所の例 | 視点 |
| --- | --- | --- |
| 共通対策・キャラ別一覧 | [イングリッドの対策ノート](ingrid/matchups/README.md) | イングリッド → 相手の共通行動 |
| キャラ別記事 | `docs/ingrid/matchups/ryu.md` | イングリッド → リュウ |
| 相手側からの補足資料 | [対イングリッド](matchups/ingrid.md) | 使用キャラ共通 → イングリッド |

共通対策の詳しい説明は、立ち回り・攻め・確反等の該当見出しへリンクする。
キャラ別には、その使用キャラで変わる反撃・距離・弾への回答と、戦略ごとの取りやすさを書く。
相手の全技表や共通対策を複製しない。

```markdown
# 使用キャラ → 対戦相手

使用キャラ：○○ / 相手：○○ / 操作：クラシックまたはモダン

## 対戦前に見ること

- 意識することを3つ程度。

## 困る行動と回答

| 相手の行動 | 条件・距離 | 自分の回答 | 通った後 |
| --- | --- | --- | --- |

## ガード後の反撃

相手の技・強度・硬直差 → 届く反撃 → 自キャラのコンボへのリンク。

## 試したいこと

再現したい状況と、比べたい行動。

## 参照

出典URL、資料の対象パッチ。
```

新キャラは[トップの一覧](../README.md)へ、キャラ別対策は使用キャラの対策一覧へリンクを足す。

## 数値と参照元

技性能は公式フレームデータを優先する。コンボ・起き攻めは、資料の対象パッチと位置・高度・ストック等の条件を併記する。**公式データ、公開レシピ、本人の実測、戦略上の仮説を区別する。**

キャラをまたいで使う考え方は[共通基礎](fundamentals.md)に置き、キャラ別ページから参照する。
キャラ側には、使う技・成立条件・一般論から変わる点を書く。

[あくあ総研](https://acqua-souken.com/)は、立ち回り・読み合い・練習方法を調べる参照先にする。
採録時は動画ノートのURLと元動画の公開日を残し、講座の助言と本ノートでの適用を分ける。
動画内の時刻は記載せず、出典へのリンクを付ける。
字幕からまとめられた内容として読み、技の数値・キャラ固有の確定状況は対象バージョンと照合する。

参照先を一つに限定せず、作者本人の調査記事・公開動画と公式技データを目的別に使う。
記載が違う場合は、始動・ヒット種別・位置・高度・消費S・集計範囲・対象時期をそろえて比べる。
条件をそろえられないダメージ差は、平均や大きい方へ統一せず、参照先と不明点を残す。

今回の構成は2026-11-03に[SF6 Labの始動・ゲージ別コンボ](https://sf6-lab.net/fighters/ingrid/combo)と[スト6原典の対策ページ](https://sf6-genten.com/character/ingrid/category/matchup)も参照して整理した。技数値・既存レシピ全件を現行版で再検証したものではない。公式ページとUFDは取得制限があり、既存値の参照先として残している。

完全技列を蓄積し、実戦で分岐を選ぶ単位が見えてから検討する。

- Route＝技列、Part＝再利用する名前付きRoute、Combo＝条件・コスト・結果付き完全Route。

- 短いTCは直書きし、全コンボを機械的に分割しない。

- Partの同一性は展開後の技列と固有の成立条件で判断する。
