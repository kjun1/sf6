# 対イングリッド

[キャラ一覧](../../README.md) · [イングリッドの攻略](../ingrid/README.md) · [技データ](../ingrid/moves.md)

**使用キャラ共通 → イングリッド。** 具体的な反撃技は、自キャラの発生と届く距離に合わせて選ぶ。以下は既存の技データと公開攻略をもとにした対策の入口。

## 対戦前に見る3点

1. **サンシンボルとODを見分ける。** ストックなしのフレアと強化版では、ガード後の有利不利が変わる。
2. **通常版サンライズをガードしたら反撃を狙う。** OD版は同じ硬直差ではない。
3. **端の有利を取り直す行動を見分ける。** 小技空振りやストック回収が、次の起き攻めの準備になっている。

## 困る行動と回答

| 相手の行動 | まず取る方針 | 注意する条件 |
| --- | --- | --- |
| 弾を置いてSを回収する | 前進・ガード・パリィを使い分け、回収の時間を自由に渡さない | 弾の停滞・再射出と対空を確認。飛びやDRを一律の正解にしない |
| `5HP`・`5HK`を振る | 空振りの差し返しやDIが機能する場面を探す | 距離とタイミング次第。`2HP`はキャンセル可能なので同じ扱いにしない |
| `DR > 5HK`をガードさせる | +2Fの攻めとして防御を選ぶ | 最速4F暴れは相手の4F小技や5F下段・投げに負ける関係。投げは間合い条件あり |
| 強化フレアをガードさせる | 不利を受け入れ、次の打撃・投げに対応する | 離れていれば投げが届かない場合もある。S回収まで自動で確定する連係ではない |
| 端でダウンを取る | 締めと時間調整を含めて、起き攻めを再現する | 空振りの小技を省くと、同じ状況にならない |

地上の技選択は[イングリッド側の地上戦](../ingrid/neutral.md)、+2Fの各択の相性は[攻めの表](../ingrid/pressure.md#dr5hk-guard)も参照。

## ガード後の反撃ポイント

硬直差は**イングリッド側から見た値**。マイナス幅以内の発生でも、距離が離れれば反撃は届かない。

| ガードした技・条件 | 硬直差 | 防御側の判断 |
| --- | ---: | --- |
| 弱 / 中 / 強サンライズ（通常版） | -24 / -23 / -25F | 届く確定反撃を選ぶ |
| ODサンライズ | -3F | 通常版の反撃を流用しない |
| 中フレア / 0Sの強フレア | -4〜-1F | 接触次第で反撃可能かが変わる。常に4F確反とはしない |
| 1S以上の強フレア / ODフレア | イングリッド有利 | ガードしただけでは確定反撃にならない |
| `2MK` / `2HK`単発 | -6 / -12F | 届くなら反撃。`2MK`のキャンセル先がある場合は別の状況 |

詳しいS別の値は[フレア](../ingrid/moves.md#sunflare)、対空無敵とガード硬直差は[サンライズ](../ingrid/moves.md#sunrise)を参照。

## トレモで比べる状況

- **フレア**：0S / 1S / 2S、通常 / ODを分けて録画し、同じ距離でガード後の行動を比べる。
- **DR強K**：ガード後の小技・投げ・シミー・ガードを別々に録画し、防御ごとの勝敗を確認する。
- **端の起き攻め**：[中ライズ後の空振り2回](../ingrid/okizeme.md#after-ender)や[前投げ後の微歩き中弾](../ingrid/okizeme.md#throw-projectile)まで含めて再現する。
