## 方向とボタン

右向き時のテンキー記法。左向きでは左右を反転する。

```text
7 8 9    ↖ ↑ ↗
4 5 6    ← ・ →
1 2 3    ↙ ↓ ↘
```

`LP / MP / HP`＝弱・中・強パンチ、`LK / MK / HK`＝弱・中・強キック。`5`はニュートラルで、`5MP`は立ち中P、`2MK`はしゃがみ中K。`236`は波動、`214`は逆波動、`66`は前ステップ。

## 技列の記号

| 表記 | 意味 |
| --- | --- |
| `>` | 目押し・追撃・実行順。回収や位置調整を挟む場合も使う |
| `:` | キャンセル |
| `~` | ターゲットコンボ（TC）・派生 |
| `j.` | 空中入力 |
| `OD.` | OD版 |
| `dl.` | 遅らせ |
| `(w)` | 空振り。時間調整などのために使う |
| `[CH]` / `[PC]` | カウンター / パニッシュカウンター |
| `[Corner]` / `[Air Hit]` | 画面端 / 空中ヒット条件 |
| `[回収2回]`等 | `214LP`のホールドによる回収回数。SA2の消費Sとは別 |
| `[3段目]`等 | 多段技のうち、次のキャンセルを行う段の指定 |

## コマンド・強度・ホールド段階

**コンボ・セットプレイの技列は、SAもコマンドで書く。** SA番号は技の分類やゲージ消費の補助説明に使う。

| 書きたいもの | 表記例 | 区別する条件 |
| --- | --- | --- |
| 弱・中・強のSA2入力 | `214214LP` / `214214MP` / `214214HP` | ボタン強度 |
| 強入力のSA2で1S消費する | `214214HP[消費1S]` | ボタン強度とシンボル消費は別 |
| OD弾の版を2ボタンで指定する | `OD.236P[弱・LP+MP]` | LP+MPは同時押し |
| 強度が分からない元レシピ | `236236P`、条件欄に「強度未特定」 | 強度共通と確認した表記とは区別 |

- `LP / MP / HP`、`LK / MK / HK`を省略せず、使う版を指定する。
- `P / K`は強度共通の説明に使う。レシピの指定が不明なら、その不明点を明記する。
- SA2は`[消費0S]` / `[消費1S]` / `[消費2S]`と書く。開始S・ボタン強度・SAゲージの消費とは別に指定する。
- SA2のホールドは、指定したS消費数になるよう調整する。
  出典のLv表記との対応は[技データの補足](ingrid/moves.md#sa2-source-levels)に置く。
- 開始S、消費S、回収回数、ODを区別する。他の技で必要なホールド段階は、その技の条件として残す。
- 分からない強度をLPやHPで補完しない。確認できたものから具体化する。

イングリッドの入力一覧は[技データ](ingrid/moves.md#super-arts)を参照。

## リソースとフレーム

| 表記 | 意味 |
| --- | --- |
| `D` | ドライブゲージ。数値の単位は1本 |
| `DR` | 生ドライブラッシュ。消費1D |
| `DRC` | キャンセルドライブラッシュ。消費3D |
| `OD` | オーバードライブ。通常は消費2D |
| `SA1 / SA2 / SA3` | スーパーアーツの分類。技列には各キャラのコマンドを書く |
| `S` | イングリッドのサンシンボル。他キャラの固有リソースは各ページで定義 |
| `BO` / `DI` | バーンアウト / ドライブインパクト |
| `F` | フレーム。`+N F`は相手よりNフレーム先に動ける状態 |

**必要数・消費数・増減は別。** 「開始1S」と「消費1S」を区別する。回収を含む場合は、どの行動までの収支なのかも記す。

有利Fだけで打撃・投げの成立は決まらない。距離、持続の当たり方、無敵、ダウン後の時間調整も条件になる。

## 分岐図の読み方

Mermaidの図は、矢印に沿って行動・局面のつながりを読む。基本は上から下、時間調整や手順の区切りは左から右に描く。

- **四角**は行動・局面。そこから「択を選ぶ」枝が出ている場合は、先に選ぶ候補を示す。
- **ひし形**はヒット・ガードなどの結果、または距離・確反猶予などの成立条件の確認。
- **戻る矢印**は再び同じ攻めや準備へ進む流れ。矢印に書いたS・有利F・距離などの条件が毎回必要。

読み合いの枝は、相手の選択を見てからすべて返せるという意味ではない。図の矢印は局面や手順のつながりで、技列の`>`・`:`・`~`とは区別する。完全入力・消費・未確認の条件は、図のそばの表・レシピ・リンク先で確認する。
