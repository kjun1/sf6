# イングリッド：画面端の攻め

> 基本戦略：[画面端でBO → DIスタン → 決着](strategy.md)。ここでは**端に到達してから、相手のDを削り続ける仕組み**を整理する。

## 端攻めの目的

1. 相手を端から逃がさない。
2. ガードすればDが減り、投げを嫌えば打撃を食らう択を作る。
3. ヒット後に同じ攻めへ戻れる締めを優先する。
4. BOしたらDIスタンの圧力を作り、残るジャンプ・SA等を咎める。

**打撃・投げ・シミー**を「相手の回答に対する再回答」として扱う。打撃だけで一方的にループが成立するわけではない。

## 1S強化214HPからの端ループ

会話で挙がった中心的なセットプレイは次の形。

```text
[画面端, 開始1S]
ヒット部分: 5MP~MK:214HP > 236HP
起き攻め準備: 214LP （1S回収）
結果の目安: 1S所持、起き上がりに対して+4F
```

- `214HP` は1Sを消費し、通常版より早く・長い多段ビームになる。
- `236HP`（強サンシュート／上方向の弾）へ追撃し、ダウンを取る。
- `214LP` で消費した1Sを戻し、**同じ攻撃性能を再び使える状態**で起き攻めに入る。
- ユーザーが挙げた **+4Fは、端・ヒット状況・入力タイミングを含むセットプレイの参考値**。別の始動や遅延入力へ無条件には流用しない。
- コマンドは `214HK` ではなく、強サンフレアの `214HP` として記述する。

注意：`214LP` はコンボとして連続ヒットする技ではなく、**ダウン後のリソース回収行動**。コンボの技列と区別して記録する。

このループの価値は火力だけではない。**S消費→S回収で開始状態へ戻り、攻めを反復できること**にある。条件に依存するため、ルートを無条件な確定ループとは扱わない。

## +4Fからの分岐

| 自分の行動 | 相手の代表的な回答 | 意図 |
|---|---|---|
| `5MP~MK` 等の打撃 | 4F暴れ、投げ抜け行動 | 暴れを潰し、ヒットから再び端ループへ |
| 投げ | ガード・パリィ | 防御を崩して投げ後の起き攻めへ |
| シミー | 遅らせ投げ抜け | 投げ空振りを差し返し、ダウン・位置を獲得 |
| 様子見・ガード | 無敵SA、Dリバーサル | 無敵行動を受けて反撃 |
| 下段・前歩き | 後ろ歩き、攻め拒否 | 逃がさず再接触 |

`5MP` は発生6Fなので+4Fからの最速重ねなら通常の4F暴れに勝てる関係。ただし届く距離と操作タイミングは前提。ターゲットコンボの2段目まで常にヒットするとは限らない。

**「ガード有利」と「投げ間合い」と「ループに戻れること」を別々に評価する。**

## 強化214HPのガード側ルート

1S `214HP` をガードさせると +4〜+8F（接触タイミングで変化）、OD0Sでも +4〜+8F。

これは攻め継続の入口となるが、**ガードされただけでは1Sが戻らない**。ヒット→236HP→214LPの再回収ループと区別する。

ガード時の距離が遠いなら、投げではなく歩き・牽制・再接触を優先する。

## 前投げ後

[UFD](https://ultimateframedata.com/sf6/ingrid)によるフレーム：

| 起点・行動 | 有利F |
|---|---:|
| 前投げ後 | +21F |
| 前ステップ | 全体20F |
| 前投げ → 最速前ステ | **+1F** |

前ステから投げの選択肢はあるが、**前ステ後+1Fの投げが相手の4F暴れに一方的に勝つわけではない**。投げの発生は5F、相手に早い打撃・無敵技・ジャンプなどの逃げ道がある。投げを通すには先に打撃の脅威を見せたい。

### 投げ後の選択

| 行動 | 狙い | 注意 |
|---|---|---|
| `66 > 投げ` | ガード・パリィを崩す | 4F暴れに対する弱さ、距離 |
| `66 > 5LP` | 暴れを止める | 最速・距離の条件。ガード後は再構築 |
| `236LP` | 再射出の弾を利用して設置・接近 | 弾抜け・SA・ジャンプ。再射出の接触時刻を考慮 |
| `236MP`（画面端・持続重ね） | ヒット時 +10F／ガード時 +6F の報告例 | タイミングと位置の条件あり。ヒット時 `2HK` 追撃候補 |
| `DR > 5HK` | ガードさせて有利を取り、択へ移行 | D消費、無敵技・Dリバーサル |
| 何もせず様子見 | 無敵技等を誘う | 圧力は下がるがリスクを抑えられる |

端投げ後の`236LP`やDR5HKは、[セットプレイ解説](https://sf6-ingrid.com/character/ingrid/category/okizeme-setplay) も参考とする。弾を出せば必ず安全、とはしない。

### 投げからの持続重ねと次の択

- **前投げ後 +21F → `DR > 5HK`**：画面端のセットプレイではヒット+9F／ガード+2F（通常のDR接触時ヒット+8Fと区別）。ガード時は `2LK`・弱攻撃・投げ・シミー・ガードから**先に選んで**ジャンケンする。
- **前投げ後 +21F → `236MP`**：持続重ねが成立すればヒット+10F（`2HK`追撃候補）、ガード+6F（届けば`2MP`・投げ・シミー）。通常の`236MP`硬直差とは異なる。
- **前投げ後 → `66`**：20F消費して残り+1F。`5LP`の4F発生は相手4Fにフレーム上先行するが、`66 > 投げ`は4F暴れに一方的に勝つ投げループではない。
- **シミー後**：`5MK[PC]:236HK`（8F）と`5HK[PC] > 5MP~MK`（9F）を状況別候補として残す。遅い`2HP`（12F）は無敵技ガード確反などで優先。

入力・ダメージ・D/S増減・投げ後から次のダウン後までの全分岐は **[行動分岐プレイブック](decision-playbook.md)** に記載する。対抗手段への表は「相手の択を見てから正解を選べる」という意味ではなく、択の勝敗・リスクを表す。

## 相手の代表的な脱出手段と回答

| 相手の行動 | 対応 |
|---|---|
| ガード・パリィ | 投げ、適切な間合いの打撃 |
| 4F暴れ | 有利時間を使った打撃重ね |
| 遅らせ投げ抜け | シミー |
| バクステ・ジャンプ | 届く打撃や対空・位置維持 |
| OD無敵技／SA | ガード・間合い外で様子見して反撃 |
| Dリバーサル | 相手が使う局面を選んでガード・回避 |
| DI返しを狙う | DIを安易に入れ込まない |

## BOとDI

BO中はガード硬直が通常より4F増える。このため普段より密な連係が作れる可能性があるが、**端でBOした相手へのDIが常に確定するわけではない**。SA・ジャンプなどの回答を含めた設計が必要。

スタン後のコンボは [コンボ・記法](combos.md) にまとめる。現時点ではダメージ最大化より、**端攻めの循環・D削り・リーサル**を優先して選択する。
