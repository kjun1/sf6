# SF6 攻略ノート

Street Fighter 6 の戦略・技データ・状況判断・コンボを、**勝ち筋から逆算して**整理する個人用リポジトリ。

## イングリッド

読む順序は「目的 → 相手の回答 → 技の選択 → 接触後の分岐 → 画面端の攻め → 必要なコンボ」。

1. [基本戦略](docs/ingrid/strategy.md) — 画面端BOからDIスタンを狙う勝ち筋とリソース運用
2. [地上戦・距離別の回答](docs/ingrid/neutral.md) — 距離ごとの基本行動、相手の標準的な対応、再回答
3. [技データと使い分け](docs/ingrid/moves.md) — 通常技のフレーム・D削り、236P/214P/236Kの役割
4. [接触後の行動分岐・確定反撃・起き攻め](docs/ingrid/decision-playbook.md) — DR強K、下段・投げ・シミー、ダメージ・ゲージ収支、ダウン後の次入力
5. [画面端の攻め](docs/ingrid/corner.md) — 強化サンフレアの循環、打撃・投げ・シミー、投げ後
6. [コンボと記法](docs/ingrid/combos.md) — 必要なコンボと表記規則。まず完全表記で管理

## 編集方針

- 対戦中の**判断基準**を優先し、コンボの本数を増やすこと自体を目的にしない。
- 確認できた数値、使用者の戦略仮説、条件付きのルートを混同しない。
- コンボは先に完全表記で蓄積する。Part参照による省略化は、全体が揃ってから行う。
- 個別の検証履歴・検証ステータスは管理しない。
- フレーム値・状況依存のセットプレイはパッチで変わるため、参照元と想定条件を明記する。
